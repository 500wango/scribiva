# Technical references (checked 2026-10-26)

- [Groq Speech to Text](https://console.groq.com/docs/speech-to-text) — model IDs, transcription endpoint, audio fields, language selection.
- [Groq API Reference](https://console.groq.com/docs/api-reference) — `/audio/transcriptions` and `/chat/completions` API surface.
- [Groq Supported Models](https://console.groq.com/docs/models) — available generation models, including `openai/gpt-oss-20b`.
- [Groq Model Deprecations](https://console.groq.com/docs/deprecations) — Llama model deprecations (2026-08); this repo does not depend on retired Llama IDs.
- [Tauri v2 Getting Started](https://v2.tauri.app/start/create-project/) — project workflow and build tooling.
- [Tauri v2 Config](https://v2.tauri.app/reference/config/) — window and bundle settings.
- [Voxtype](https://github.com/peteonrails/voxtype) — reference Linux multi-backend text input strategy; no code copied.
- [xdg-desktop-portal RemoteDesktop API](https://flatpak.github.io/xdg-desktop-portal/docs/doc-org.freedesktop.portal.RemoteDesktop.html) — Wayland authorization and input mechanisms.
