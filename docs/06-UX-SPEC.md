# Scribiva v1.0 — 交互与界面规格

## 1. 核心 UX 原则

**说话时不离开当前应用；处理结果不丢失；对系统权限诚实。** 主界面只需要首次引导、设置、用量/订阅和问题诊断，日常通过托盘 + 轻量悬浮条完成。

## 2. 信息架构

```text
Scribiva
├── Onboarding（隐私告知、麦克风、会话检查、快捷键、本月免费额度）
├── Tray Menu（开始/停止录音、模式、设置、退出）
├── Floating HUD（Idle/Recording/Processing/Ready/Failure）
├── Settings
│   ├── General（开机启动、热键、插入策略）
│   ├── Audio（输入设备、增益测试）
│   ├── Language（自动/手动 20 种语言、中文简繁）
│   ├── Writing（原文 raw / 智能修正 standard / 流畅表达 polished、口述格式命令开关）
│   ├── Dictionary（个人词典：添加、导入、导出、删除）
│   ├── Privacy（音频处理、结果清除、诊断选择）
│   ├── Linux compatibility（Wayland/X11 诊断和输入后端）
│   └── Account & Billing（用量、升级、管理订阅）
└── Recovery（最近一次文字、复制、重试、丢弃）
```

## 3. 状态反馈

| 状态 | 主文案（示例） | 可执行动作 |
|---|---|---|
| Idle | 按快捷键开始说话 | 打开设置 |
| Recording | 正在录音 · 00:12 | 停止 / 取消 |
| Processing | 正在转写… | 取消后续插入 |
| Correcting | 正在修正语法… | 取消后续插入 |
| Ready | 已准备文字 | 插入 / 复制 / 查看原文 |
| Focus Changed | 输入位置已变化，为避免误贴，已暂停 | 复制 / 指定目标后插入 |
| Clipboard Only | 当前系统环境不允许自动输入 | 复制 / 查看设置方法 |
| Focus Unknown | 无法确认输入位置，已复制到剪贴板 | 粘贴 / 安装 GNOME 扩展 / 在设置中开启未校验插入 |
| Suspected Noise | 未检测到清晰语音，结果未插入 | 查看结果 / 插入 / 丢弃 |
| Quota | 本月免费额度已用完，将于 X 月 1 日重置 | 升级 / 管理订阅 |
| Error | 转写失败，录音未丢失 | 重试 / 删除 |

录音必须显著标注；悬浮条不可抢走目标编辑器焦点。若 HUD 导致焦点变化，必须修复或使用不聚焦窗口。

## 4. 新用户引导

1. **价值介绍**：任意支持的编辑器直接语音输入；20 种语言；智能语法修正。
2. **隐私透明**：告知需要上传音频至美国服务器识别/处理，列出第三方提供商（Groq）；用户同意后继续。
3. **登录**：打开浏览器完成邮箱魔法链接登录，返回应用后显示本月免费额度（FR-019）。
4. **麦克风测试**：显示录音信号、设备选择、权限拒绝时可理解的修复指引。
5. **环境检测**：Windows 或 Linux；Linux 展示 X11 / Wayland 和可用后端；GNOME Wayland 引导安装 Scribiva 扩展，KDE 引导启用 KWin 脚本，未安装时说明将以“只复制”模式运行（ADR-012）；要求权限时解释原因与可撤回方式。
6. **快捷键**：建议可自定义组合，并检测与操作系统/编辑器冲突；支持桌面环境原生绑定的用户配置。
7. **Obsidian / 浏览器 10 秒测试**：用户在输入框中执行一条短转写；失败时不继续声称安装成功。
8. **每月免费额度和升级**：显示本月剩余时长与重置时间（本地时区），付费价格以服务端真实价为准。

## 5. 写作模式交互

默认：`standard`（界面标签“智能修正”），提供清晰、短标签。选择 `raw` 时必须不强制调用 LLM；选择 `polished` 需要提示“可能改变措辞，请校对”。结果预览可一键在“原文/修正版”之间切换，然后复制/插入。不能在用户没有明确操作时修改已有文档。

## 6. 焦点、安全与剪贴板体验

- 在录音和处理之间切走应用：**禁止自动写入切换后的应用**，显示结果预览。
- 用户主动选中一段文字：首版需明确“替换选区”行为；撤销不能删除选区以外内容。
- 用户正在打字或编辑另一个窗口：宁可不自动插入，也不抢焦点。
- 剪贴板被外部程序改动：不强行恢复旧内容；可提示“剪贴板内容已被其他应用更新”。
- 密码输入框和权限提升窗口：默认不自动插入，并提供适当错误解释。

## 7. Obsidian 特殊体验

不需要用户安装 Obsidian 插件。只在编辑视图里插入光标位置；Reading View 显示“当前不是可编辑区域”；Markdown 格式处理只针对**本次输出片段**。提供“原文模式”快捷切换，以保护代码和特殊标记。

## 8. 无障碍和多语言 UI

- 首发界面语言可先有英文/简体中文；**语音支持 20 语言 ≠ UI 翻译成 20 语言**，官网须明确区分。
- 所有控件有标签、键盘焦点状态、屏幕阅读器友好名称和非颜色唯一状态提示。
- RTL 文本预览正确排版；用户自定义快捷键可用键盘完成。
- Linux 安装引导中，系统命令必须解释风险并由用户明确触发，不自动使用管理员权限。

## 9. UI 验收

- 录音开始后 200ms 内显示状态（初始目标，需要实测）。
- 所有状态允许通过 Esc 或明确按钮中止/退出；行为在不同平台一致。
- 任意错误状态都允许查看并复制安全的诊断信息，不包含音频正文或敏感窗口标题。
- 新手无需打开主窗口即可完成第二次听写。

## 10. 文案规范

不得使用“Linux 全发行版完美支持”“所有应用 100% 兼容”“AI 语法零错误”。使用“已测试支持：Windows 11、Ubuntu 24.04 X11/GNOME Wayland、Fedora XX KDE Wayland（以实际 QA 为准）”之类的明确声明。
