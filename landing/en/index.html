Press a hotkey, speak, and the words land at your cursor.

Scribiva is voice dictation for Windows and Linux. In Obsidian, your browser, a document or your IDE, press the hotkey once to start and again to stop. The transcribed, cleaned-up text is inserted where you were writing.

Download for Windows / Linux See pricing

Includes a monthly free allowance. Speech is processed in the cloud on Scribiva servers in the USA. See how your data is handled.

One dictation, four steps

Day to day you never open the main window. A tray icon and a small overlay that doesn’t steal focus are all you need.

  1. Put your cursor in a text field

    Any supported editor: notes, documents, email, browser text boxes.

  2. Press the hotkey and speak

    The overlay shows “Recording” and a timer. The hotkey is customizable.

  3. Press it again to stop

    Scribiva notes the target window and starts transcribing and correcting.

  4. Text appears at the cursor

    Before inserting, it checks the target window is unchanged. If it changed, the text is copied for you to paste.

Speak casually, get text you can use

Three writing modes
  • RawWord-for-word transcript, no language-model edits.
  • StandardThe default. Adds punctuation, removes filler words, fixes clear grammar mistakes, keeps your meaning.
  • PolishedSmoother written style. May change wording, so give it a read.
Protected content

Code, commands, file paths, URLs, email addresses and Markdown structure stay character-for-character. Numbers keep their value; only formatting like “half past three” to “3:30” may change. If correction fails, you get the raw transcript.

Personal dictionary

Add names, product names and code identifiers. Recognition and correction both respect them. Your dictionary is stored with your account and can be exported or deleted.

Spoken formatting

Say “new line”, “new paragraph” or “bullet” (in Chinese: 换行, 新段落, 列表项). Fixed rules turn them into line breaks, blank lines and Markdown lists. You can switch this off in settings.

No phantom text from silence

Made-up phrases that speech models sometimes produce from silence or noise, like “thanks for watching”, are filtered. Suspicious results go to the recovery area instead of being inserted.

No wrong-window pastes, no auto-send

If Scribiva can’t confirm the target window, it copies the text to the clipboard instead of pasting. It never presses Enter, so it won’t send messages or run commands. Terminal windows are copy-only by default.

Tested with Obsidian

Live Preview and Source Mode are a dedicated test target, covering Markdown, line breaks and undo. No Obsidian plugin required.

Your text is kept

If inserting fails or the network drops, your latest text stays on your computer, ready to copy, retry or discard.

Where Scribiva won’t type

  • Windows running as administrator
  • Password fields
  • The lock screen
  • Remote desktop sessions

Also worth knowing

  • No macOS or mobile version yet.
  • Not every Linux distribution or Wayland compositor is supported.
  • Requires an internet connection; there is no offline recognition.

How your voice is processed

Scribiva is not an offline tool. Audio from every dictation is uploaded for cloud processing. Here is the full path.

Where: the USA

Audio goes to Scribiva servers in the USA, which use Groq for speech recognition and text editing. The app never connects to Groq directly. For users in mainland China, this is a cross-border data transfer.

How long it’s kept

Audio is processed in memory and not stored. Result text is kept on the server for up to 15 minutes so you can recover it after a network drop.

Recording only when you ask

There is no always-on microphone. The overlay is visible while recording, and cancelling a recording means nothing is uploaded.

Delete any time

Delete your data from the account page or run scribiva service delete --confirm. Billing records are kept as financial regulations require. See the privacy policy.

Questions

Does it work offline?

No. Recognition and correction run in the cloud, so you need a connection. When you’re offline Scribiva says so clearly and doesn’t interfere with your system input method.

Why does it sometimes copy instead of pasting?

Scribiva only types for you when it can confirm the target window hasn’t changed. If you switched windows while it was processing, or the system doesn’t expose the focused window (GNOME Wayland without the extension, KDE Wayland today), it copies the text so it never lands in the wrong place.

Will it send messages or run commands for me?

No. Scribiva never presses Enter, never submits forms and never acts on instructions in your speech. Terminal windows are copy-only by default.

Do I need an Obsidian plugin?

No. Put your cursor in Live Preview or Source Mode. Reading View isn’t editable, so Scribiva tells you and keeps the text.

Will it translate what I say into English?

No. Speak Japanese and you get Japanese; speak Chinese and you get Chinese. Scribiva is not a translator.

What happens when the free allowance runs out?

Before you start recording, Scribiva shows how much time is left this month and when it resets. If one recording goes past what’s left, that recording is still processed in full. After that, wait for the monthly reset or upgrade to Pro.

Does it work in mainland China?

The site, downloads and app only connect to Scribiva servers in the USA and don’t rely on other overseas resources. Because speech is processed in the USA, using Scribiva means your data is transferred across borders; please read the privacy notice before first use. Cross-border connections may be slower.
