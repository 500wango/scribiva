按下快捷键说话，

Scribiva 是 Windows 与 Linux 上的语音输入工具。在 Obsidian、浏览器、文档或 IDE 里，按一次快捷键开始说话，再按一次停止，识别并修正后的文字会插入你正在写的位置。

四步完成一次听写

日常使用不需要打开主窗口，托盘图标和一个不抢焦点的小悬浮条就够了。

  1. 把光标放进编辑区

    任意受支持的编辑器：笔记、文档、邮件、浏览器输入框。

  2. 按快捷键开始说话

    悬浮条显示“正在录音”和计时。快捷键可自定义。

  3. 再按一次停止

    Scribiva 记下当前目标窗口，开始转写与修正。

  4. 文字写入光标处

    插入前再次确认目标窗口没变；变了就只复制，交给你粘贴。

说得随意，写出来是能直接用的文字

三档写作模式
  • 原文逐字转写，不经过语言模型修改。
  • 智能修正默认模式。补标点、去口头禅、修正明确的语法错误，保留原意。
  • 流畅表达整理成更通顺的书面语，可能改变措辞，建议校对。
不乱改的内容

代码、命令、文件路径、URL、邮箱和 Markdown 结构在修正前后逐字保持；数字的数值不变，只允许“三点半”写成“3:30”这类书面化。修正失败时回退到原始转写。

个人词典

把人名、产品名、代码标识符加进词典，识别和修正时都会按词典保留。词典随账户保存，可导出和删除。

口述格式命令

说“换行”“新段落”“列表项”（英文为 “new line”“new paragraph”“bullet”），由固定规则转成换行、空行和 Markdown 列表。不需要时可在设置中关闭。

静音不出幻觉文字

静音或噪声里冒出的“谢谢观看”之类虚构文字会被过滤；可疑结果只放进恢复区，不自动插入。

不误贴、不替你发送

如果无法确认目标窗口，Scribiva 只把文字复制到剪贴板，不粘贴。它从不按回车，不会替你发送消息或执行命令。终端类窗口默认只复制。

Obsidian 专项测试

Live Preview 与 Source Mode 是重点测试场景，覆盖 Markdown、换行和撤销。不需要安装 Obsidian 插件。

结果不丢

插入失败或网络出错时，最近一次文字保留在本机，可复制、重试或丢弃。

你的语音如何被处理

Scribiva 不是离线工具。每次听写的音频都会上传到云端处理，下面是完整的路径。

处理地点：美国

音频发送到 Scribiva 位于美国的服务器，由服务器调用 Groq 完成语音识别和文字修正。客户端不直接连接 Groq。对中国大陆用户而言，这属于数据出境。

保存多久

音频只在内存中处理，不落盘保存。识别结果在服务器上最多保留 15 分钟，用于网络中断后的恢复。

只在你按下快捷键时录音

没有后台常开的麦克风。录音时悬浮条始终可见，取消录音不会上传。

随时删除

可在账户页删除数据，或运行 scribiva service delete --confirm。账单记录按财务法规保留。详见隐私政策。

常见问题

可以离线使用吗？

不可以。识别与修正都在云端完成，需要联网。断网时 Scribiva 会明确提示，不影响系统自带的输入法。

为什么有时只复制、不自动粘贴？

Scribiva 只在确认目标窗口没有变化时才自动写入。如果你在处理期间切换了窗口，或者系统不提供焦点信息（例如未安装扩展的 GNOME Wayland、当前的 KDE Wayland），它会把文字复制到剪贴板，避免贴进错误的地方。

会替我发送消息或执行命令吗？

不会。Scribiva 从不按回车，也不会提交表单或执行语音中的指令。终端类窗口默认只复制。

Obsidian 需要装插件吗？

不需要。在 Live Preview 或 Source Mode 中把光标放好即可。Reading View 不是可编辑区域，Scribiva 会提示并保留文字。

会把我的话翻译成英文吗？

不会。说日语就写日语，说中文就写中文。Scribiva 不是翻译工具。

免费额度用完了会怎样？

开始录音前会提示本月剩余时长和重置日期。如果某一段录音超出剩余额度，这一段仍会完整处理；之后需要等下月重置或升级 Pro。

在中国大陆能用吗？

官网、下载和应用只连接 Scribiva 的美国服务器，不依赖其他境外资源。由于语音在美国处理，使用即意味着数据出境，请在首次使用前阅读隐私告知。跨境网络的速度可能比海外慢。
